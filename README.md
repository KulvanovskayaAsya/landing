# Частная психотерапевтическая практика

Astro 5 · TypeScript · Tailwind CSS 4 · PhotoSwipe

```bash
npm install
npm run dev
npm run build
```

Перед публикацией обновите:

- `src/data/site.ts` — URL сайта, Telegram, Instagram
- `public/images/portraits/` — реальные портреты
- `public/images/certificates/` — сканы дипломов и сертификатов (+ размеры в `src/data/certificates.ts`)
